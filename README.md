# E-Commerce Store

A full-featured e-commerce store built with React, React Router, and Context API.

## Features

- Product listing grid with 13 products
- Product detail page
- Shopping cart (add, remove, adjust quantity)
- Category filtering (Electronics, Clothing, Books, Home)
- Price sorting and search
- Checkout form with validation
- Dark theme with emerald accent

## Tech Stack

- React 19 + Vite
- React Router DOM for navigation
- React Context API + useReducer for cart state

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build

```bash
npm run build
```
